# 🏡 StayFinder (Airbnb Clone)

A modern Airbnb-inspired property rental website built using React.js and Vite.

## ✨ Features

- Responsive Homepage
- Property Listings
- Property Details Page
- Favorites System ❤️
- Search & Filter
- Categories
- Contact Page
- About Page
- Experiences Page
- FAQ Section
- Testimonials
- Newsletter Subscription
- Responsive Design

## 🛠 Tech Stack

- React.js
- Vite
- React Router DOM
- CSS3
- JavaScript

## 🚀 Installation

Clone the repository

```bash
git clone <repository-link>
```

Install dependencies

```bash
npm install
```

Run the project

```bash
npm run dev
```
